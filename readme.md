# TinyTroupe Bulk Simulation App

This is a **production-ready TinyTroupe simulation app** with 50 realistic personas.

## Features
- Run simulations with multiple personas
- Dynamic number of simulation rounds
- Summary dashboard with traits and demographics
- Download simulation results (CSV / JSON)
- Fully deployable on **HuggingFace Spaces** or any Streamlit environment
